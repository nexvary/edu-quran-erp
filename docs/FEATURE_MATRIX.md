# مصفوفة الخصائص — Edu Quran ERP

هذه الوثيقة تفصل **المتاح في نواة Gibbon** عن **المنفذ في QuranHifz** و**الخصائص المخطط لها**. لا يعني وجود ميزة داخل النواة أننا اختبرناها بعد في مشروعنا.

| المجال | نواة Gibbon المفتوحة | QuranHifz v1 الحالية | مستهدف الدمج المتقدم |
| --- | --- | --- | --- |
| سجلات الطلاب والعائلات | متاح | استخدام معرفات Gibbon | تحسين القبول والأرشفة |
| المستخدمون وصلاحيات الأدوار | متاح | إدارة فقط | المشرف والمعلم وولي الأمر بصلاحيات صفّية |
| المواد والفصول | متاح | لا تعديل | ربط المناهج بالخطة القرآنية |
| الجداول الدراسية | متاح | جلسات الحلقات | جدول موحد مع تعارضات |
| الحضور المدرسي | متاح | لا تعديل | مقارنة مع حضور التحفيظ |
| الحضور القرآني | ليس وحدة قرآنية أصلًا | تسجيل وتعديل حالة حضور | اعتماد غياب وإشعارات |
| الحلقات | تخصيص إضافي مطلوب | إنشاء وتسجيل طالب | مستويات وطاقة استيعابية ونقل |
| المعلم القرآني | ربط بالموظفين | إسناد لكل حلقة | لوحة معلم مستقلة |
| الحفظ الجديد | يحتاج تخصيصًا | السورة + الآيات + التقييم | صفحات وأجزاء وتقدم يومي |
| المراجعة | يحتاج تخصيصًا | تسجيل مراجعة | مراجعة متباعدة وتحليل النسيان |
| التجويد | يحتاج تخصيصًا | تقييم عام من 100 | معايير مستقلة للأحكام |
| الامتحانات والدرجات | متاح مدرسياً | تقارير متوسط التسميع | اختبار القرآن والشهادات |

| تعدد الفروع | تصميم جديد مطلوب | غير منفذ | فصل الفروع وتقارير مركزية |
| واجهة العربية | يعتمد على تعريب بيئة Gibbon | واجهات عربية RTL | توحيد كامل للواجهة |
| اختبار MySQL | اختبار مستقبلي للتكامل | اختبار مخطط الجداول على CI | اختبار تطبيق كامل |

## مبدأ التنفيذ

نحافظ على بيانات الطالب وشؤون المدرسة في Gibbon ونضيف الجداول القرآنية فقط، بدل بناء نظام ثانٍ له سجل طلاب مختلف. يُختبر كل تكامل على إصدار محدد قبل اعتباره مدعومًا.
