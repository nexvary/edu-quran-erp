# واجهة Edu Quran ERP — Design System v2

**الحالة:** التحديث منشور في شفرة الإضافة، واجهة Gibbon المتكاملة غير مختبرة بعد في متصفح خادم فعلي.

## الهوية

- Midnight Navy: \`#0a1424\`، \`#0d1b2e\`
- Deep Surface: \`#111f31\`، \`#192b40\`
- Emerald: \`#72dcb8\`، \`#61d5b4\` — التحفيظ والتقدم
- Electric Blue: \`#6ca7fb\` — الطلاب والمدرسة
- Muted Gold: \`#e5c480\`، \`#d8b778\` — الإجراءات البارزة
- كل الأيقونات SVG محلية ضمن \`qhIcon()\`، وليست Emoji أو روابط لأيقونات خارجية.
- خطوط نظام احتياطية بالعربية وRTL.
- التنقل الفعلي لا يعرض روابط لصفحات غير منفذة.
- تخطيط متجاوب 4 بطاقات على المكتب، بطاقتان على الهاتف، ولوحتان متجاورتان أو متكدستان.
- حالات فارغة توضح للمستخدم الخطوة المطلوبة بدلاً من جداول بيضاء بلا محتوى.

## حدود الادعاء

- وظيفة Gibbon الأساسية للمدرسة لم تُعاد صياغة واجهتها في هذا التحديث؛ التغيير خاص بوحدة \`QuranHifz\`.
- لا توجد أرقام افتراضية داخل شاشات PHP؛ تستخدم استعلامات قاعدة البيانات. التصميم الاستعراضي إن وُجد تُوسم أرقامه بوضوح بأنها تجريبية.
- إتاحة المعلمين والطلاب وأولياء الأمور وإدارة الفروع ليست منجزة بعد.
- اختبار PHP وأساس جداول MySQL لا يساوي اختبار قابلية استخدام متكامل على Gibbon. يلزم QA بصري/وظيفي بعد تركيب الوحدة.

## معايير قبول الواجهة

1. عدم قص النصوص العربية عند أحجام 360–1440 بكسل.
2. تنقل لوحة مفاتيح واضح وعناصر يمكن تمييزها بصريًا.
3. كل رابط يوصل إلى صفحة قائمة، وكل إجراء يُرسل إلى \`save.php\`.
4. عدم عرض قيم إحصائية مفترضة على أنها سجلات حقيقية.
5. احترام التصاريح الحالية وعدم كشف صفحة للطالب أو ولي الأمر.
6. التأكد من تحميل ملف CSS في Gibbon عند فتح شاشة التحفيظ.
