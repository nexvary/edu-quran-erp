# Edu Quran ERP | نظام إدارة المدرسة ودار تحفيظ القرآن

**الحالة:** نسخة تطوير أولية (MVP) — غير جاهزة للإنتاج أو إدخال بيانات طلاب حقيقية.

مشروع يجمع **النواة المدرسية المفتوحة المصدر [Gibbon](https://github.com/GibbonEdu/core)** مع إضافة **QuranHifz** التي تطور وظائف تحفيظ القرآن. ندرس متطلبات الأنظمة التجارية InfixEdu وSmart School بصفتها مرجعًا للوظائف فقط، دون نسخ شفرتها.

## ما تم تنفيذه
- لوحة إحصائية خاصة بدار التحفيظ.
- إنشاء حلقات وإسناد معلمين من موظفي المدرسة.
- إلحاق الطلاب المدرجين في Gibbon بالحلقات.
- جلسات مؤرخة لكل حلقة.
- تسجيل الحضور (حاضر/غائب/بعذر).
- الحفظ الجديد والمراجعة بالسورة ونطاق الآيات والتقييم والملاحظات.
- تقارير لكل طالب تتضمن عدد التسميع ومتوسط التقييم والحضور المسجل.
- صلاحيات إدارية افتراضية، واستعلامات SQL مجهزة، وحماية CSRF والتحقق من المدخلات.
- اختبار للمدخلات وسير عمل للتحقق من بنية PHP.

## بدء التشغيل (بيئة تطوير فقط)
المتطلبات: Git وDocker وPHP/Composer حسب [دليل Gibbon الرسمي](https://docs.gibbonedu.org/guides/install/installing-gibbon).

```bash
git clone https://github.com/nexvary/edu-quran-erp.git
cd edu-quran-erp
bash scripts/install-local.sh
cd core
composer install
./up.sh
```

بعد تثبيت Gibbon وتهيئة قاعدة البيانات وإتمام معالج التثبيت، افتح **System Admin → Manage Modules** وثبّت **QuranHifz**. قد يختلف تسلسل الإعدادات تبعًا لإصدار Gibbon وبيئتك. لم يتم التحقق بعد من التثبيت المتكامل على خادم فعلي.

يمكن أيضًا نسخ المجلد `modules/QuranHifz` إلى مجلد `modules/` لأي نسخة Gibbon متوافقة ثم تثبيته من لوحة الإدارة.

## الاختبارات
